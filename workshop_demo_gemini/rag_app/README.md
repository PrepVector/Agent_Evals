# RAG QA app (Exercises 1 & 2) — Gemini version

A single-turn Q&A bot over the same "Voltaic Labs" fixture data used by
the Section 6 research agent.

## Files

- `app.py` — `answer_question(question)`. Requires `pip install google-genai`
  and your own free `GEMINI_API_KEY`.
- `Exercise1_Golden_Eval_Set.ipynb` — read the source docs, write 15-20
  test cases (5+ outside happy-path), run them all through the bot.

## Setup

The notebook's first cell handles installation and cloning — just replace
`PASTE_KEY_HERE` with your API key and run it.
